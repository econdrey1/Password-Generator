I created this Password Generator as a beginner Python project to practice using loops, lists, random choices, and user input.
The program asks the user how many letters, numbers, and symbols they want in their password. It then randomly selects the characters, mixes them together, and creates a password based on the user’s choices.
What I Learned
While working on this project, I practiced:
- Using input() to get information from the user
- Converting user input into integers
- Using for loops
- Working with lists
- Using random.choice()
- Using random.shuffle()
- Adding items to a list with .append()
- Combining characters to create a final password
How It Works
The user chooses how many:
- Letters they want
- Symbols they want
- Numbers they want
The program randomly selects the requested characters, stores them in a list, shuffles the list, and combines everything into one password.
